# Contributing to BetterGroup

Use short branches such as:

```text
fix/tab-drag
fix/chat-shield
fix/multi-staff
feature/history
feature/installer
```

Before opening a pull request, test the relevant cases in `docs/TEST_MATRIX.md`.

Do not commit:

- compiled DLL/EXE files;
- build folders;
- personal logs;
- absolute personal paths;
- TruckersMP artwork;
- GitHub tokens or other secrets.

For visual bugs, attach a short video/screenshot and, if debug mode is enabled, `BetterGroup.log`.
